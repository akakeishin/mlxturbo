# 投機デコード研究ダイジェスト（2026-08-26 調査）

Phase D の設計根拠。全項目一次ソース確認済み（末尾の確度注記を除く）。
詳細な調査全文はセッションログにあり、ここは実装判断に必要な部分だけ。

## 最重要の事実

- fastmlx の受理崩壊（難文で平均 1.0〜1.5）は vanilla MTP 連鎖の既知パターン。
  位置別受理率の相場: k=1 ~70% / k=2 ~11% / k=3 ~2%（FastMTP 論文の実測）
- **FastMTP** (arXiv:2509.18362) が同一シナリオの解: 単一 MTP ヘッドを
  position-shared で再帰適用できるよう微調整（backbone 凍結、位置減衰 CE
  α_k ∝ 0.6^(k-1)、K=3、自己生成データ 389K、H20 1枚 1日未満）。
  結果 k=2 56% / k=3 36%、平均 2.03 倍
- 巻き戻し設計（射影一括+再帰逐次+全位置状態保持）は SpecLA (2607.16673) の
  factor buffering / Bole (2608.01651) と同型。fastmlx の新規性は
  「Apple Silicon / MLX / ハイブリッド 3:1 での移植と実測」と主張する
- ドメイン合わせの警告 (2605.30580): 一般ドメイン蒸留はほぼ無効果
  (受理 0.39 / 1.03 倍)。実使用分布の自己生成データ必須（合成でも実データの
  80〜93% に届く: 2503.07807）

## 即日で入る訓練不要の改善

- **AdaEDL** (2410.18351): ドラフトのエントロピーから受理下界を近似して連鎖を
  打ち切る。パラメータフリー。静的深度比 10〜57% 改善
- **Sequoia の最適化式** (2402.12374): Speedup = G(n,d)/(t(n)+d·c) に
  実測 t(m)（m カーブ）を代入して最適 m を解く。
  **Leviathan 閉形式は検証コスト線形仮定なので fastmlx の超線形カーブに使用禁止**
- **BanditSpec** (2505.15141): 深度を腕、実測 tok/s を報酬にした UCB。
  コスト曲線を式にせず吸収できる代替
- **Block Verification** (2403.10444): ブロック同時棄却で分布厳密のまま
  wall-clock +5〜8%。棄却サンプラの差し替えのみ
- **Attention Drift 診断** (2605.09992): 連鎖位置ごとの ĥ の RMS を真の h と比較。
  膨張していれば推論時スカラー再スケールという訓練ゼロの応急処置が試せる

## lookup / 混成の設計図

- **SAM-Decoding** (2411.10666, ACL 2025, 実装公開): 静的+動的の二重 suffix
  automaton で厳密最長一致を平均 O(1)。現行の O(n) 走査の置換先
- **ReSpec** (2511.01282): 混成仲裁の上位互換。エントロピー閾値で retrieval 起動、
  一致位置ごとの受理率 EMA、source-aware verification。Vicuna-7B で 3.05 倍
- **SuffixDecoding** (2411.04975): 一致長 p に比例した投機深度 (MAX_SPEC=α·p)。
  運用注意: CPU 側 20〜30µs/token が律速になった報告あり。専用ハッシュで 3.4 倍

## 木投機（当面見送り。着手条件つき）

- GDN の木は Bole (2608.01651) が閉形式カーネルで解決済みだが CUDA 前提、
  Metal 移植は数週間規模
- **警告** (2505.22179): 4bit 量子化の帯域利得は木検証の計算増で相殺される。
  fastmlx は直撃対象。木化は A2 カーネル完成後に GOOSE (2604.02047) の
  異方的 spine（chain 軸 + 確信度低下点だけ横に広げる）から
- GDN 層だけを内部ドラフトに使う案は追わない。sequential hybrid での実測が
  受理率 α=0.038 (2605.01106) で、実用にならない。STree も対角 A 限定で
  GDN には適用できない

## L3 / KV 側の相互作用

- KV 圧縮は target 分布をずらし最適深度もずらす (SpecKV 2605.02888)。
  L3 で KV 量子化するなら深度適応か ヘッド再調整を前提に
- fastmlx は KV 16 層のみで疎化レバーが小さく、TriForce 系の価値は中
